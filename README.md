# devops-netology - Элдияр Акматов

`git diff` показывает изменения перед `staged`, после `git add` просто git `diff` уже не показывает если в git нет файла со статусом `modified`, `git diff --staged` показывает изменения со статусом `staged`

В будущем благодаря файлу `terraform/.gitignore` будут проигнорированы:
- Файлы состояния (State): `*.tfstate, *.tfstate.*` - хранят текущее состояние инфраструктуры и блокировки, могут содержать чувствительные данные и меняются при каждом запуске.

- Служебный каталог `.terraform/` — локальный кэш, куда Terraform скачивает провайдеры и модули (тяжёлые файлы)

- Файлы с переменными и секретами `*.tfvars, *.tfvars.json` — содержат значения переменных, в которых часто хранятся пароли, ключи и специфичные параметры.

- Локальные переопределения и кэш `override.tf, *_override.tf, crash.log, .terraformrc` — временные логи ошибок, конфигурации и локальные правки

Символ `*` обозначает любое, например все файлы с расширением `.tfvars` `*.tfvars`, или часть названия если после символа * идет словосочетания `*_override.tf` 

Символ `/` ставится для обозначения каталога, например игнорировать каталог .venv `.venv/`
